# Sample sources

- The generated DOCX, workbook, and OpenDocument samples use fictional travel, group, and shop data. They do not describe company projects, personnel, technical decisions, customers, or financial results.

- `filens-field-notes.pptx`: project-created, editable three-slide “Beyond the Visible” presentation, generated by `scripts/generate-showcase-documents.mjs`. Uses the pale-blue aurora and NASA nebula images credited below.
- `filens-weekend.key`: project-created three-slide “Beyond the Visible” Keynote presentation. Generated in Keynote using `scripts/generate-keynote-sample.applescript`, with the credited aurora and nebula images. The existing filename is retained for shared sample links.
- `filens-aurora-guide.docx`, `filens-observatory.xlsx`, and `filens-cosmic-atlas.pdf`: project-authored photographic field guide, fictional observation workbook, and three-page visual atlas. Generated by `scripts/generate-showcase-documents.mjs`; exposed by the existing DOCX/XLSX/PDF demo buttons. Text, tables, formulas, and PDF vectors remain native document content.
- `showcase/aurora.jpg`, `showcase/aurora-banner.jpg`, and `showcase/aurora-portrait.jpg`: cropped, **pale-blue color-graded derivatives** of “Aurora Borealis Norway 2013” by **Carsten**, [Wikimedia source](https://commons.wikimedia.org/wiki/File:Aurora_Borealis_Norway_2013.jpg), [CC BY 2.0](https://creativecommons.org/licenses/by/2.0/). The original aurora is green; this artistic grade is not a scientific color record. This photograph is used in document artwork, not mapped as a spherical panorama.
- `showcase/cosmic-cliffs.jpg` and `showcase/cosmic-cliffs-square.jpg`: cropped/resized derivatives of “NASA’s Webb Reveals Cosmic Cliffs, Glittering Landscape of Star Birth”. Image: **NASA, ESA, CSA, STScI**, public domain. [Original image and credits](https://webbtelescope.org/contents/media/images/2022/031/01G77PKB8NKR7S8Z6HBXMYATGJ), [Wikimedia source](https://commons.wikimedia.org/wiki/File:NASA%E2%80%99s_Webb_Reveals_Cosmic_Cliffs,_Glittering_Landscape_of_Star_Birth.jpg).
- `showcase/milky-way-360.jpg`: resized 4096×2048 tone-mapped JPEG of **Rogland Clear Night** by **Greg Zaal / Poly Haven**, [asset source](https://polyhaven.com/a/rogland_clear_night), [CC0](https://polyhaven.com/license). The full 2:1 equirectangular image is preserved for actual 360° viewing.
- `showcase/midnight.png`: project-created solid navy background for native Keynote slides.

Prepare the photography with `python3 scripts/prepare-showcase-images.py` (Pillow required), then regenerate the Office/PDF files with `node scripts/generate-showcase-documents.mjs`. Keynote regeneration requires macOS and Keynote; pass an output `.key` path and the absolute `samples/showcase` directory to the AppleScript.

- `filens-cafe.dxf`: project-created fictional cafe concept plan with walls, windows, doors, furniture, plants, and dimensions, generated by `scripts/generate-showcase-cad.mjs`. It does not depict a real site.

External proprietary-format validation files are not redistributed with the demo:

- Insta360 One RS 1-inch `.INSP`, `.INSV`, and `.LRV` samples: https://360rumors.com/download-1-inch-360/ — the source permits personal viewing only. Browser validation uses the 6528x3264 JPEG-based `.INSP`, the 768x384 H.264 `.INSV` proxy, and the 768x384 H.264 low-resolution `.LRV` dual-fisheye proxy (`LRV_20220625_140410_11_008.insv`) from the associated Google Drive folder.
- DJI Osmo 360 `.OSV` and matching `.LRF` samples: https://huggingface.co/datasets/SamuelLDX/osmo360-lidar-preview — the dataset license is marked `other`. Browser validation uses the camera-generated 2048x1024 H.264 `.LRF` proxy rather than attempting to decode the dual-fisheye HEVC streams directly.
