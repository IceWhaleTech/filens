# Homepage visual assets

All preview screenshots and the walkthrough were captured from this project's running previewers. The file badges are locally drawn identifiers. The photographs below are embedded in real sample documents; document screenshots are not flattened substitutes for those files.

The official ZimaOS logo used in the recommendation section is documented in [brand/SOURCES.md](../brand/SOURCES.md).

- `presentation.webp`: the project-created, editable `samples/filens-field-notes.pptx` presentation, “Beyond the Visible”. The cover uses a cropped, pale-blue color grade of **Carsten**'s “Aurora Borealis Norway 2013”, [Wikimedia source](https://commons.wikimedia.org/wiki/File:Aurora_Borealis_Norway_2013.jpg), [CC BY 2.0](https://creativecommons.org/licenses/by/2.0/). The original image is green; the artistic blue grade is not a scientific color record.
- `landscape.webp`: resized derivative of that pale-blue aurora photograph.
- `document.webp`: the project-authored `filens-aurora-guide.docx`. Its fictional polar itinerary includes the same credited aurora and a NASA Webb image.
- `spreadsheet.webp`: the project-authored `filens-observatory.xlsx`. Stations, observations, scores, and exposure plans are fictional. The file contains native cell values and formulas; preview styling follows the workbook driver's current capabilities.
- `pdf.webp`: the project-authored, three-page `filens-cosmic-atlas.pdf`, with native PDF text and vectors alongside the credited aurora and NASA Webb images.
- `iwork.webp`: the native Keynote version of “Beyond the Visible”, `filens-weekend.key`, rendered by filens. It contains the credited aurora and NASA Webb imagery.
- `cad.webp`: the project-generated `filens-cafe.dxf` fictional cafe floor plan.
- `model.webp`: the project-authored `samples/viking-helmet.obj`, a stylized horned Viking helmet with a steel dome, bronze trim and rivets, nasal guard, cheek plates, and ivory horns. Generated by `scripts/generate-showcase-helmet.mjs` with vertex colors and explicit normals; no external model, material, or texture is required. This is a fantasy costume design.
- `panorama.webp`: a perspective view of **Rogland Clear Night** by **Greg Zaal / Poly Haven**, [asset source](https://polyhaven.com/a/rogland_clear_night), [CC0](https://polyhaven.com/license). The bundled source remains a complete 4096×2048 equirectangular image for 360° viewing.
- `video.webp`: the native video preview playing the bundled MDN flower video, `samples/sample-video.mp4` ([CC0 source](https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4)).
- `music.webp`: the audio preview of the project's synthesized `tone.wav` melody, with project-authored synchronized LRC text and the public-domain **Cosmic Cliffs** cover credited below. The melody and lyrics are created in `apps/demo/src/App.vue`.
- `archive.webp`: the archive browser showing the project-generated `preview-bundle.zip` sample, including nested folders, Unicode filenames, source code, and data files.
- `ebook.webp`: the ebook reader showing the illustrated cover and chapter navigation of `samples/pepper-carrot.epub`. The sample packages the first two pages of **David Revoy**'s **Pepper & Carrot**, episode 1, “The Potion of Flight” ([original comic](https://www.peppercarrot.com/en/webcomic/ep01_Potion-of-Flight.html), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)). English proofreading: **Amireeti and Alex Gryson**. The cover crops the first panel of page 2; both full pages are preserved in the next chapter. The EPUB packaging and cover typography are project-authored in `scripts/generate-showcase-ebook.mjs`.
- `filens-demo.mp4`: a real recording of the redesigned workbench and these samples, with slide controls, format search, a collapsible library, worksheet switching, a zoom and orbit around the Viking helmet, a panorama drag, video playback, music with cover art and synchronized lyrics, and local document import. It includes the credited aurora, Milky Way, Cosmic Cliffs, and MDN flower imagery. The recording is distributed under CC BY-SA 4.0, has no audio track, and includes `demo-zh.vtt` / `demo-en.vtt` chapter captions.
- `demo-poster.webp`: a still frame from the Viking helmet chapter of the walkthrough.

The additional **Cosmic Cliffs** imagery in the sample documents is by **NASA, ESA, CSA, STScI**, public domain. [Original image and full credits](https://webbtelescope.org/contents/media/images/2022/031/01G77PKB8NKR7S8Z6HBXMYATGJ). [Full sample provenance and preparation](../samples/SOURCES.md).

Regenerate with `node scripts/capture-homepage-demo.mjs` while the local demo server is running. It authors the Office/PDF samples and captures their actual previews using Playwright Chromium and FFmpeg. Native Keynote is generated separately with `scripts/generate-keynote-sample.applescript`; its second argument is the absolute `samples/showcase` directory. `FILENS_DEMO_URL` overrides the default local URL. Screenshots use WebP; the walkthrough uses H.264 MP4 with fast-start metadata. The homepage shows one preview at a time and does not preload video bytes.

For a UI refresh using the existing sample files, run `node scripts/capture-homepage-demo.mjs --reuse-samples`, followed by `node scripts/generate-readme-assets.mjs`. This updates all preview captures, the recording, poster, caption tracks, media cache version, and README visuals without regenerating sample documents.

For a helmet-only refresh, run `node scripts/capture-homepage-demo.mjs --model-only`, followed by `node scripts/generate-readme-assets.mjs`. This regenerates the OBJ, its preview capture, the full walkthrough and translated captions, its helmet poster, and the README overview / animated preview, while keeping the other sample documents and preview captures intact.

For a video/music refresh, run `node scripts/capture-homepage-demo.mjs --media-only`. This updates only `video.webp`, `music.webp`, the full walkthrough, translated captions, poster and media cache version, preserving all sample documents and other preview captures.

For the four additional README previews, run `node scripts/capture-homepage-demo.mjs --readme-only`, followed by `node scripts/generate-readme-assets.mjs --overview-only`. This refreshes only the video, music, ZIP archive, and EPUB ebook captures, then regenerates the README overview, preserving the sample documents, walkthrough, and animated preview.

For an ebook-only refresh, run `node scripts/generate-showcase-ebook.mjs`, `node scripts/capture-homepage-demo.mjs --ebook-only` with the demo server running, and `node scripts/generate-readme-assets.mjs --overview-only`. This uses the bundled comic artwork and preserves all other captures and recordings.
