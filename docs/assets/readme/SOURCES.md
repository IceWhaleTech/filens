# README visuals

- `overview.webp` combines six actual filens preview captures and locally drawn file badges. It includes the cropped Alpine lake photograph by Ricardo Gomez Angel (Unsplash License) and a perspective derivative of SimonWaldherr's Kochelsee Panorama (CC BY-SA 4.0). The composite is distributed under CC BY-SA 4.0.
- `demo.gif` is a resized, accelerated derivative of the project's screen recording, distributed under CC BY-SA 4.0. The original MP4 is linked from both READMEs for full-speed playback.
- The document shown is a fictional weekend travel guide. Sample groups and figures are invented; the recording contains no internal technical decisions, staff details, or host storage paths.

Full photo links, licenses, sample provenance, and recording details: [homepage visual sources](../../../apps/demo/public/home/SOURCES.md).

Regenerate the captures first, then run `node scripts/generate-readme-assets.mjs`. The script requires Playwright Chromium and FFmpeg. Both language versions use the same visuals; their captions and surrounding content are translated.
