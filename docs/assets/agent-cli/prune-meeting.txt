会议背景
团队正在准备文档读取工具的下一个版本。本次会议讨论发布计划、费用上限和部署依赖。
项目需要同时覆盖个人用户的离线使用，以及上层 Agent 的自动调用。

核心决议
决定采用本地 RapidOCR NCNN，统一设置最大边长960、OpenMP线程2，不引入私有Python环境。
预算不得超过12345.67元；新增支出必须由负责人张三审批。
截止日期为2026年11月6日，Windows实机验证完成后才允许正式发布。

风险与行动
风险：极小字体和严重模糊的扫描件可能漏字，关键金额必须核对原图。
负责人李四将在周五前完成Windows完整包与轻量包的OCR测试。
未完成实机验证时，只提供候选包，不宣称Windows运行已经通过。
