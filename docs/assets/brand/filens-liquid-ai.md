# filens · Liquid AI logo

The filens app icon with a folded document, a glass magnifier,
and a vivid cyan / blue / violet / pink / orange gradient.

- Editable master: `filens-liquid-ai.svg` (1024-unit viewBox).
- High-resolution export: `filens-liquid-ai-2048.png` (2048 × 2048, RGBA).
- Preview export: `filens-liquid-ai-512.png` (512 × 512, RGBA).
- PNGs are rasterized directly from the SVG at their final resolution.
- Colors, highlights, glass rims, and shadows are defined in the SVG.

The material and depth reference is Apple's official Preview App Store icon:
https://apps.apple.com/us/app/preview/id536344167

The geometry is drawn for filens; a single document with a compact folded corner,
document lines, and a magnifier handle preserve the project's file-preview identity.

Production assets use the same design:

- `apps/demo/public/brand/filens-icon.svg`: homepage, preview workbench,
  README logos, and SVG favicon.
- `apps/demo/public/brand/filens-icon-{32,180,512}.png`: raster icons.
- `packaging/zimaos/icon.svg`: ZimaOS app icon.
