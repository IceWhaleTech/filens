# Converter Fixtures

This directory contains controlled samples for the manifest-backed OpenXML conversion matrix used by `wasm/converter-core` and the Go/wazero wrapper.

`manifest.json` is the source of truth for fixture smoke tests. Only files referenced by that manifest are part of the default conversion policy; any historical or locally generated files that are not referenced by `manifest.json` are ignored by the current smoke matrix.

The Go wrapper only hosts `converter-core.wasm` through wazero. Parsing and OpenXML generation happen inside the WASI core.

## Maintenance

Regenerate the controlled fixtures and manifest from `wasm/converter-core/manifest/conversions.json` with:

```sh
npm run fixtures:converter
```

Check that the generated bytes and manifest have not drifted with:

```sh
npm run fixtures:converter:check
```

Run the WASM smoke test from the repository root with:

```sh
npm run build:wasm
npm run test:wasm-smoke
```

The smoke test runs every job in `manifest.json`, validates the resulting OpenXML package, and inspects generated XML entries for expected fixture content. Successful outputs are lightweight preview artifacts, not production-fidelity Office conversions.
